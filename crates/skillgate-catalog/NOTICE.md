# Attribution

The catalog feature was designed with reference to the MIT-licensed AgentDex
project by CaptainYouz/Anas:

- <https://github.com/CaptainYouz/agentdex>

This crate is an independent implementation for Skillgate's versioned AppAPI.
It retains AgentDex's useful high-level convention of discovering AI-tool
artifacts from `.cursor`, `.claude`, `.codex`, and `.agents` directories, while
using new data types, grant-based path authorization, stable identifiers,
filtering, error handling, and tests.
