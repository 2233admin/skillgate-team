# Skillgate compatibility ledger

This is the blocking compatibility contract for the React + Tauri 2/Rust migration. The immutable Skillgate baseline is commit `37b09a4525a3a34b64c03b325f2ff33e0132cada` (`37b09a4`). Agentdex capabilities may extend Skillgate, but they may not close or weaken any row below.

`baseline-captured` records an existing commitment only. A row becomes `verified` after both its automated and manual checks pass and its migrated-target artifact is written under `.omx/evidence/`. `secure-deviation` is permitted only when the changed behavior, threat, migration impact, and approval are captured in the evidence record.

## Ownership boundaries

- **Team API**: `cli/src/team-api` remains canonical for profile resolution, Apply, Doctor, Lock, Protect, and catalog drift. Rust and UI adapters must not reimplement these rules.
- **CLI/TUI**: the TypeScript CLI and OpenTUI remain supported clients that work without Desktop.
- **Platform/Rust**: Tauri owns persistence, filesystem mediation, agent detection, SSH, file watching, platform integration, and updates behind App API v1.
- **Renderer**: React owns routes, presentation, settings/favorites UX, and localization; it does not access the filesystem or database directly.

## Release gate

The migration is not compatibility-complete while any row is `baseline-captured`, `in-progress`, or `blocked`, or while either evidence artifact is missing. A `secure-deviation` row is release-eligible only with explicit threat, behavior delta, user impact, migration, automated evidence, manual approval, and rollback evidence.
