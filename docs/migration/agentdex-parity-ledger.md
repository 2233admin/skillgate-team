# Agentdex parity ledger

This ledger freezes the user-visible Agentdex baseline at commit
`7b9a54197e6ef23fab0f651e784231e67413598f`. A row is complete only when the
target evidence exists and its listed automated and manual checks pass. Agentdex
is evidence, not the target architecture: the resulting product remains
Skillgate and the target owners below refer to Skillgate components.

## Status vocabulary

- **Status:** `baseline-captured`, `in-progress`, `blocked`, `verified`, or
  `not-applicable`. Every row starts as `baseline-captured`.

## Exact discovery contract

The baseline recursively scans the selected base directory (home by default,
`%USERPROFILE%` on Windows) and treats a config directory directly below the
base as global. The same config directory below any other folder is project
scope, named after that folder. It does not follow directory links and skips the
noise/cache/build directories listed in `src-tauri/src/scanner.rs`.

## Completion gate

No legacy Agentdex implementation may be deleted until its row is `verified`.
No unsafe legacy implementation may be used as runtime rollback: a
`secure-deviation` rollback means disabling the action or reverting the entire
signed Skillgate release. A parity milestone is complete only when all rows have fresh
target evidence, all README coverage remains mapped, and no row is
`in-progress` or `blocked`.
